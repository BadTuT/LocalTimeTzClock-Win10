# Build 26300 支持实施计划

**目标：** 在 v15 的安全边界内增加真实 SystemTray.dll 2609.11000.100.0 的配置和主时钟数据源策略。

**设计：** [新版支持设计](../specs/2026-11-02-build26300-design.md)。用户已授权继续执行，沿用 smart-dispatch 指定的 Google Antigravity，实现后由主代理独立验收。

## 全局约束

- 不合并、不推送、不改变系统时区，不在真实 Explorer 中运行挂钩。
- 旧版使用原格式化策略；新版仅修改 GetLocalTime IAT，并严格区分主显示数据源、定时调度。
- 不扩大至未经核实的 2609.12001.100.0 或其他 Build 26300 二进制。
- 版本及文件名同步 v16；新增文档、注释使用简体中文。

## 审查重点

- 附加时钟与主时钟共享格式化函数：新版的格式化 IAT 必须完全不变。
- 主数据源读取不改变秒数、不消费 kick；定时器仍读系统时间。
- off、未知调用、无效目标时区透传；旧版的写入及失败测试继续通过。
- 模块身份和完整调用点集合严格验证，不能只匹配 7/7 数量。
- 确认真实下载样本及符号来源，避免把模拟验证写成真机通过。
